\paragraph{Literal (a)}\mbox{}\\
Denotemos por \(t_n\) el número de teselaciones de una cinta de tamaño \(1\times n\) utilizando cuadrados y dóminos. Utilizando argumentos combinatorios, demuestre que:
\[
\text{(i) }t_0 + t_1 + \cdots + t_n = t_{n+2} - 1,
\quad
\text{(ii) }t_0 + t_2 + t_4 + \cdots + t_{2n} = t_{2n+1}.
\]
¿Qué identidades sobre los números de Fibonacci se deducen a partir de estas igualdades?
