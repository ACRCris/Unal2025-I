Demuestre, utilizando argumentos combinatorios, que para todo \(n\ge1\) se cumplen las siguientes identidades para los números de Stirling de segunda clase:
\[
\left\{n\atop2\right\} = 2^{n-1}-1,
\quad
\left\{n\atop n-1\right\} = \frac{n(n-1)}2,
\quad
\left\{n\atop n-2\right\} = \binom n3 + 3\binom n4.
\]
